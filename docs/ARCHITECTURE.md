# Архитектура

## Принцип
Статический сайт без сборки и без сервера: чистые HTML, CSS и JavaScript. Его можно открыть двойным щелчком по `index.html` и бесплатно выложить на GitHub Pages.

## Структура папок
```
barbershop-site/
├── index.html          каркас страницы, мета-теги, пустые контейнеры
├── css/
│   └── styles.css      дизайн-токены, макет, адаптив
├── js/
│   ├── data.js         ВСЁ содержимое: бренд, филиалы, цены, акции, настройки
│   └── app.js          отрисовка из data.js, фильтр, меню, форма записи
├── assets/
│   └── favicon.svg
├── docs/
│   ├── PLAN.md
│   └── ARCHITECTURE.md
├── GITHUB.md           пошаговая инструкция по GitHub
├── README.md
└── .gitignore
```

## Поток данных
```
data.js (SITE_DATA, CONFIG)
        │
        ▼
app.js ── render() ──► контейнеры в index.html
        │
        ├─ фильтр филиалов по району
        ├─ мобильное меню
        └─ форма записи ──► ссылка wa.me / t.me с готовым текстом
```
Содержимое отделено от вёрстки: чтобы сделать сайт для другого барбершопа, правят только `data.js` и пару цветов в CSS.

## Решения и компромиссы
| Решение | Почему | Цена решения |
|---|---|---|
| Без фреймворка | Проще понять, быстро грузится, нечего ломать при обновлении | Нет компонентов, всё вручную |
| Контент в `data.js` | Один файл для правок | Поисковики видят текст только после выполнения JS (Google его выполняет, но статичный HTML индексируется надёжнее) |
| Запись через WhatsApp/Telegram | Не нужен сервер и база | Нет учёта записей; для этого понадобится бот или CRM |
| Шрифты с Google Fonts | Есть кириллица, красивые | Нужен интернет; в РК иногда медленно, есть системный запасной шрифт |

## Дизайн-токены (css/styles.css)
- Цвета: `--ink` тёмно-синий, `--pole` красный, `--paper` холодный светлый, `--steel` сталь.
- Шрифты: Unbounded для заголовков, Onest для текста (оба с кириллицей).
- Один «громкий» элемент на страницу: анимированный барберский столб в главном экране. Остальное сдержанное.

## Доступность и качество
- Семантические теги, `aria-label` у кнопок без текста, видимый фокус.
- `prefers-reduced-motion`: анимация столба отключается.
- Адаптив: сначала мобильная версия, брейкпоинты 720px и 1040px.
- Форма: проверка имени и телефона до отправки.

## Куда развивать
1. Казахская версия: переключатель RU/KZ, строки вынести в `data.js` по языкам.

4. Метрика и пиксель для аналитики рекламы.
