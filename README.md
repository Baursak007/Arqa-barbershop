# ARQA Barbershop: шаблон сайта

Статический одностраничный сайт барбершопа на HTML, CSS и JavaScript. Без сборки и без сервера.

## Запуск
Откройте `index.html` в браузере. Для проверки на телефоне загрузите проект на GitHub Pages (см. `GITHUB.md`).

## Как переделать под другого клиента
1. Откройте `js/data.js` и замените бренд, филиалы, цены, акции и тексты.
2. В `CONFIG` укажите номер WhatsApp и имя Telegram-бота (или личного аккаунта) для заявок. Клиент сам выбирает канал в окне записи. Подробности и пояснения к каждому полю в комментариях внутри `js/data.js`. Токен бота в этот файл не записывать.
3. Цвета меняются в начале `css/styles.css` (блок `:root`).
4. Замените `assets/favicon.svg`.

Все названия, адреса, телефоны и цены в проекте являются заглушками.

## Скорость и поиск
- Пока контент грузится, на его месте серые заготовки («призрачная загрузка»), а не крутилка.
- Шрифты подгружаются отдельно (`js/fonts.js`), страница не ждёт Google.
- Для поисковиков: после смены адреса сайта, филиалов, часов или цен запусти `node tools/seo.js`. Он обновит описание, структурированные данные, `sitemap.xml` и `robots.txt`. Адрес сайта задаётся в `js/data.js` (`siteUrl`).
